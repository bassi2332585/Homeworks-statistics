Welford's Algorithm, Sampling Mean & Variance, and Inferential Statistics

Exercise 1: Derivation of Welford's Recurrence Formulas

Online, numerically stable algorithm for computing sample mean, sum of squares (SS), and variance in a single pass.

1. Mathematical Proof for Mean & Sum of Squares

Let $\bar{x}_k$ be the mean of the first $k$ data points $x_1, \dots, x_k$. Knuth's recurrence for the mean is:

$$\bar{x}_k = \bar{x}_{k-1} + \frac{x_k - \bar{x}_{k-1}}{k}$$

Define the sum of squared differences $M_k = SS_k = \sum_{i=1}^k (x_i - \bar{x}_k)^2$. To express $M_k$ in terms of $M_{k-1}$:

$$M_k - M_{k-1} = \sum_{i=1}^k (x_i - \bar{x}_k)^2 - \sum_{i=1}^{k-1} (x_i - \bar{x}_{k-1})^2$$ $$= (x_k - \bar{x}_k)^2 + \sum_{i=1}^{k-1} \left[ (x_i - \bar{x}_k)^2 - (x_i - \bar{x}_{k-1})^2 \right]$$

Using the identity $(a-b)^2 - (a-c)^2 = (c-b)(2a - b - c)$ with $b=\bar{x}_k$ and $c=\bar{x}_{k-1}$:

$$M_k = M_{k-1} + (x_k - \bar{x}_{k-1})(x_k - \bar{x}_k)$$

Sample variance $s_k^2$ (with Bessel's correction $k-1$) and population variance $\sigma_k^2$ are then given by:

$$s_k^2 = \frac{M_k}{k-1} \quad \text{for } k \ge 2, \qquad \sigma_k^2 = \frac{M_k}{k}$$

2. Concise Code Implementation (Core 3 Lines)

The core algorithm requires updating three state variables per data point $x_k$ at step $k$:

// Core 3-line update logic per item x at step k
const delta = x - mean;
mean += delta / k;
M += delta * (x - mean); // M = SS_k
// Sample variance: s2 = M / (k - 1)
